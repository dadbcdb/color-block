# 컬러 탈출 · 블록 퍼즐

사진 위의 블록을 밀어 같은 색 출구로 탈출시키는 퍼즐 게임입니다. 5개 스테이지, 터치 이동, 방향키 이동, 되돌리기를 지원합니다.

## 아이폰에서 인터넷 없이 실행하기

1. GitHub의 저장소 화면이 아니라 **GitHub Pages로 배포된 게임 주소**를 Safari로 엽니다.
2. **오프라인 준비 완료**가 표시될 때까지 기다립니다. 게임, 사진, 아이콘을 모두 기기에 저장한 다음에만 이 문구가 표시됩니다.
3. Safari의 **공유 → 홈 화면에 추가**를 누릅니다. ‘웹 앱으로 열기’가 표시되면 켜둡니다.
4. 홈 화면 아이콘으로 처음 실행할 때는 인터넷을 켜두고, 다시 **오프라인 준비 완료**를 확인합니다. Safari와 홈 화면 앱의 저장 공간이 다를 수 있습니다.
5. 앱을 닫은 다음 비행기 모드에서 홈 화면 아이콘으로 실행해 확인합니다.

이후에는 로그인과 인터넷 연결 없이 실행할 수 있습니다. iOS가 저장 공간을 정리하거나 사용자가 웹사이트 데이터를 지우면 다시 접속해 저장해야 합니다. 개인 정보 보호 브라우징 대신 일반 Safari를 사용하세요.

## GitHub Pages 배포

저장소 관리자 권한으로 **Settings → Pages → Build and deployment → Source: Deploy from a branch**를 선택하고, 배포할 브랜치의 **/(root)** 폴더를 지정합니다. 배포가 끝나면 Pages 설정에 표시되는 HTTPS 주소를 사용합니다. 저장소 파일을 복사한 것만으로 Pages가 활성화되는 것은 아닙니다.

빌드 도구나 서버 없이 이 폴더를 그대로 배포합니다. 상대 경로를 사용하므로 `/color-block/` 같은 저장소 하위 경로에서도 작동합니다. `.nojekyll`은 Jekyll 처리를 건너뜁니다.

## 개발 및 검사

```sh
python3 -m http.server 4173
node --test tests/offline.test.mjs
```

`http://localhost:4173`에서 실행합니다. 서비스 워커는 HTTPS 또는 localhost에서만 사용할 수 있으므로 HTML 파일을 직접 열어서는 오프라인 설치가 되지 않습니다.

테스트는 서비스 워커의 전체 파일 캐시, 네트워크 없는 페이지/사진/스크립트 응답, 저장 실패 상태, 캐시 범위 분리, 하위 경로 호환성을 확인합니다. 실제 iPhone 실행 검사는 별도로 필요합니다.

## 파일 수정 후 업데이트

게임 파일, 사진, 아이콘 등을 바꾸면 **sw.js의 VERSION도 새 값으로 변경**하세요. 서비스 워커 설치가 성공한 버전만 활성화되며, 이 앱 범위 안의 이전 캐시만 정리합니다. 새 버전이 저장된 뒤 앱을 완전히 닫았다 다시 열면 새 파일을 사용합니다.

## 포함 파일

- `index.html`, `game.js`, `levels.js`: 게임
- `board-photo.jpg`: 사용자가 제공한 바닥 배경 사진
- `pwa.js`, `sw.js`: 오프라인 설치 상태 및 캐시
- `manifest.webmanifest`, `icons/`: 홈 화면 앱 정보 및 아이콘

Android 서명 키, 인증 정보, APK 빌드 도구는 포함하지 않았습니다.
