GitHub 저장 연결

dadbcdb/color-block에 맵을 저장합니다. 이 저장소의 쓰기 권한이 있는 연결 키(Personal Access Token)를 입력하세요.

키는 이 탭에서만 사용하며, 맵 파일이나 브라우저 저장소에는 남기지 않습니다. 채팅으로 보내지 마세요.

연결 키 만드는 방법
  1. GitHub의 Fine-grained token 만들기를 엽니다.
  2. Repository access에서 color-block 저장소만 선택합니다.
  3. Repository permissions의 Contents → Read and write를 선택합니다.
  4. 만든 키를 이 입력칸에 붙여넣습니다.
